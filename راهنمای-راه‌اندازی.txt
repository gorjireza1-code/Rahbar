بسته وب اپلیکیشن راهبری آموزشی

محتویات:
- index.html: فایل اصلی برنامه
- manifest.webmanifest و آیکون‌ها: مشخصات نصب برنامه روی گوشی
- sw.js: ذخیره پوسته برنامه برای اجرای آفلاین پس از اولین بارگذاری

روش راه‌اندازی پیشنهادی با GitHub Pages:
1) وارد حساب GitHub شوید و یک مخزن (Repository) جدید بسازید؛ مثلاً با نام rahbar-amoozeshi.
2) مخزن را Public قرار دهید.
3) همه فایل‌های داخل این پوشه را (نه خود پوشه) در ریشه مخزن بارگذاری کنید؛ به‌ویژه index.html، manifest.webmanifest، sw.js و دو آیکون.
4) از Settings مخزن، بخش Pages را باز کنید.
5) در قسمت Build and deployment، گزینه Deploy from a branch را انتخاب کنید؛ Branch را روی main و پوشه را روی /(root) قرار دهید و Save را بزنید.
6) پس از آماده‌شدن انتشار، نشانی HTTPS نمایش‌داده‌شده را با Chrome گوشی باز کنید.
7) ابتدا اجازه دهید صفحه یک بار کامل بارگذاری شود. سپس از منوی سه‌نقطه Chrome گزینه Add to Home screen یا Install app را انتخاب کنید (اگر نمایش داده شد).
8) از این پس همیشه از همان نشانی HTTPS و همان مرورگر/گوشی استفاده کنید. برای استفاده آفلاین، برنامه باید ابتدا یک بار با اینترنت باز شده باشد.

نکات مهم حفاظت از اطلاعات:
- این بسته به‌تنهایی فضای ابری یا همگام‌سازی بین چند گوشی ایجاد نمی‌کند؛ اطلاعات هر دستگاه در حافظه همان مرورگر ذخیره می‌شود.
- پیش از انتقال از فایل قبلی، از نسخه قبلی با گزینه «پشتیبان کامل با تصاویر» خروجی JSON بگیرید و آن را در محل امن نگه دارید. سپس در نسخه وب از گزینه «بازیابی/ادغام پشتیبان» استفاده کنید.
- تا زمانی که از بازیابی و صحت اطلاعات مطمئن نشده‌اید، فایل قبلی و پشتیبان را حذف نکنید و داده‌های Chrome را پاک نکنید.
- نشانی وب را تغییر ندهید و از حالت ناشناس (Incognito) استفاده نکنید.
- برای جلوگیری از ازدست‌رفتن اطلاعات، به‌طور منظم پشتیبان کامل بگیرید و فایل را خارج از گوشی نیز نگه دارید.

این بسته بر پایه نسخه ۱۳۶ موجود تهیه شده است. انتشار عمومی در GitHub Pages نیازمند انجام مراحل بالا توسط صاحب حساب است؛ من به حساب GitHub شما دسترسی ندارم و نمی‌توانم از طرف شما آن را منتشر کنم.
